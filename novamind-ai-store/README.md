# NovaMind — AI-inspired Shopping Website

A responsive multi-page front-end website concept for a Web Development assignment.

## Pages (10)
1. `index.html` — home page with 20 content sections
2. `shop.html` — searchable and filterable product collection
3. `product.html` — product detail layout
4. `ai-assistant.html` — interactive shopping assistant demo
5. `gift-finder.html` — gift finder form
6. `style-quiz.html` — interactive style quiz
7. `categories.html` — category gallery
8. `about.html` — brand story
9. `journal.html` — editorial/blog page
10. `contact.html` — contact form

## Features
- Custom SVG logo and dark premium visual theme
- Responsive mobile-first CSS with tablet and desktop media queries
- CSS Grid, Flexbox, sticky navigation, hover states, scroll reveal animations
- JavaScript mobile menu, localStorage cart counter, product search/category filters, toast notifications, demo chat, quiz, FAQ accordion, and demo forms
- External Unsplash image URLs are used for product/editorial photography; internet is required to load those images and Google Fonts.
- AI assistant responses are simulated in front-end JavaScript. For real AI, connect a secure backend; never expose API keys in client-side JavaScript.
- Product prices, cart and forms are demonstrations only. No payment or actual order submission.

## Run locally
Open `index.html` in your browser, or use VS Code Live Server for the best experience.

## Assignment note
The attached assignment brief specifies HTML and CSS, responsive layout, navigation, hero, cards, gallery/testimonials, footer, media queries, and compulsory deployment. This project adds JavaScript interactions because requested. If your instructor requires *only HTML and CSS*, keep `script.js` as an optional enhancement or remove its script tags and interactive controls.
